# منصة أيهم التعليمية

موقع عربي بسيط ومتجاوب لتدريس مواد الجامعة.

## الروابط
- رابط المستودع: https://github.com/ayhmabwkwsh064-ops/-
- رابط الموقع المتوقع بعد النشر عبر GitHub Pages: https://ayhmabwkwsh064-ops.github.io/-/

## الملفات
- `index.html`
- `style.css`
- `script.js`
- `.github/workflows/deploy-pages.yml`

## ماذا يفعل المشروع
- عرض المواد الجامعية
- تصميم عربي احترافي
- خطة دراسة
- أسئلة شائعة
- نموذج تواصل
- نشر تلقائي عبر GitHub Pages عند كل تحديث

## التعديل السريع
يمكنك تعديل:
- اسم الموقع
- أسماء المواد
- معلومات التواصل
- النصوص والأقسام
- ربط كل مادة بصفحة أو PDF أو فيديو
