# منصة أيهم التعليمية

موقع عربي بسيط ومتجاوب لتدريس مواد الجامعة.

## الملفات
- `index.html`
- `style.css`
- `script.js`

## طريقة التشغيل
افتح ملف `index.html` مباشرة أو ارفع الملفات على GitHub Pages.

## التعديل السريع
يمكنك تعديل:
- اسم الموقع
- أسماء المواد
- معلومات التواصل
- النصوص والأقسام
- ربط كل مادة بصفحة أو PDF أو فيديو

## مناسب لـ
- التدريس الجامعي
- الدورات القصيرة
- الملخصات والأسئلة
- عرض المواد والخطة الدراسية
